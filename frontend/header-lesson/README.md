# header-lesson — บทเรียน Header แบบ Responsive (Next.js 16 + Tailwind CSS v4)

โค้ดเต็มที่ทำเสร็จแล้วของบทเรียน — วิธีทำทีละขั้นอยู่ในเอกสาร [`NEXT_HEADER_GUIDE.md`](../../NEXT_HEADER_GUIDE.md) ที่ root ของ repo

```bash
npm install     # ครั้งแรกครั้งเดียว
npm run dev     # เปิด http://localhost:3000
```

ไฟล์หลักของบทเรียน: `src/components/Header.tsx` · เมนู: `src/lib/menu.ts` · กรอบทุกหน้า: `src/app/layout.tsx`
