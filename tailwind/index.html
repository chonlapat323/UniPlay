บทที่ 0

Tailwind คืออะไร — "ตกแต่งด้วย class"

ปกติเราเขียน CSS แยกไฟล์แล้วตั้งชื่อ class เอง แต่ Tailwind มี class สำเร็จรูปให้หลายพันตัว 1 class = 1 การตกแต่ง เอามาต่อกันใน class="..." ได้เลย

CSS แบบเดิม (2 ที่)

<button class="my-btn">จอง</button>

.my-btn {
  background: #4f46e5;
  color: white;
  padding: 8px 16px;
  border-radius: 8px;
}

Tailwind (ที่เดียวจบ)

<button class="bg-indigo-600 text-white
               px-4 py-2 rounded-lg">
  จอง
</button>

วิธีเริ่มใช้ (ไม่ต้องติดตั้งอะไร)

  1. เปิดไฟล์ practice.html ในโฟลเดอร์เดียวกันนี้ด้วย VS Code (ตั้งค่าส่วน <head> ไว้ให้แล้ว)
  2. หัวใจคือบรรทัดนี้ใน <head>: <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
  3. คัดลอกโค้ดจากบทไหนก็ได้ ไปวางใน <body> → บันทึก → ดับเบิลคลิกไฟล์เปิดในเบราว์เซอร์ (ต้องต่ออินเทอร์เน็ต)

ผลลัพธ์ของทั้งสองแบบเหมือนกัน 👇
